A Python 3.13 program (stdlib only) that writes one original one-liner about a hilariously useless superpower to `/output/entry.txt`: the power to control the weather, but only in a one-metre circle around yourself, and only to make it slightly worse. Deterministic — every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
